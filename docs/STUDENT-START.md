# Project Showcase 시작하기

1. 학생용 ZIP을 프로젝트 최상위에 풉니다. `.claude/skills/project-showcase/SKILL.md`가 있어야 합니다. macOS 숨김 폴더는 Command+Shift+.로 확인합니다.
2. 스킬의 `references/setup.md`를 따라 **전용 `.showcase-venv`**를 준비합니다. 기존 프로젝트 `.venv`는 변경하지 않습니다.
3. 제작 전에 `preflight`를 실행합니다. PASS는 도구 환경 시험 통과이며 발표자료·영상 합격은 아닙니다.
4. Claude Code에서 `/project-showcase`를 실행하거나 아래 문장을 요청합니다.

> project-showcase 스킬로 현재 프로젝트의 전체 구조와 핵심 사용자 흐름을 분석해 줘. 실제 근거로 5분 발표용 HTML 8장과 3분 한국어 음성·자막 영상을 만들어 줘. 각 입력에 맞는 실제 결과 화면을 확보하고 발화와 화면 변화를 연결해 줘. 실행하지 못한 기능과 측정하지 않은 효과는 구분해 줘. 대본·스토리보드는 한 번에 보여 주고, 마지막에는 내가 전체 영상을 듣고 확인할 수 있게 알려 줘.

준비할 것: 실행법, 안전한 데모 데이터, 보여 줄 실제 입력·출력. edge-tts에는 발음용 원고가 온라인으로 전송되므로 고객·개인정보를 제거합니다.

수정할 때:

> 마지막 결과의 상태를 읽고 [수정 내용]을 반영해 줘. 정상 음성은 재사용하고, 수동으로 수정한 HTML은 보호해 줘. 재생성이 필요하면 백업되는 --regenerate를 사용하고 필요한 검사를 다시 해 줘.

실제 MP4를 처음부터 끝까지 듣고 제품명·숫자 발음, 자막·화면 연결, 마지막 음절을 확인합니다. 그 결과를 Claude Code에 알려 주세요. 청취 전 결과는 `export --draft`로 검수 대기 ZIP을 만들 수 있습니다. 청취 확인 후 `finish`, `export`로 제출 묶음을 만듭니다. sample 예제는 실제 프로젝트 완료와 구분합니다.

최종 ZIP 안의 `START-HERE.txt`와 `MANIFEST.json`에서 상태를 확인하세요. 덱은 `deck/index.html`, 영상은 `showcase.mp4`입니다. 덱 조작은 ←/→·Enter(이동), Home/End(처음/끝), 1~8(장 선택), F(전체화면), ?(도움말)입니다. 데모의 state 선택 버튼으로 각 실제 결과 화면을 볼 수 있습니다. assets를 함께 유지해야 합니다.

30분은 사전 준비 완료 후의 목표입니다. 환경·네트워크·내용 수정에 따라 달라집니다. 문제가 생기면 임의로 파일을 지우지 말고 state.json과 오류 메시지를 담당자에게 전달하세요.
