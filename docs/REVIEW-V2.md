## 품질 평가

v1의 동일한 두 열 반복에서 문제·비교·흐름·데모·표·마무리로 구성이 구분됐다. 데모 영역 확대와 상태 버튼은 발표자가 입력과 결과를 설명하기 좋다. 영상의 배송·환불·미분류 상태 교체와 확대는 말하는 대상의 화면 근거를 보여 준다. 한글 제목, 본문, 자막의 대비와 위계가 안정적이다. 30분 제작 제약에서는 장식적인 전환을 추가하기보다 현재 의미 일치와 읽기 쉬운 화면을 유지하는 것이 적합하다.

## 한계와 남은 완료 조건

이번 재검토는 변경 구간 중심의 차등 시각 검토다. 최신 산출물 전체 프레임을 연속 재생하지 않았고 실제 음성을 청취하지 않았다. 최종 MP4 인코딩 이후 데모 전환/장면 경계/종료 프레임 샘플을 확인해야 한다. 실제 나레이션의 발음, 말속도, 끊김, 청감상 화면 싱크와 행사장 프로젝터 가독성은 별도 확인 대상이다. 프레임 검수 허용을 최종 배포·음성 검수 완료로 간주하지 않는다.

## 후속: 최종 MP4 추출 프레임 확인

최종 영상 `showcase-output/v2-example/renders/showcase-1795189794311530000.mp4`에서 추출된 실제 PNG를 직접 확인했다. 원영상 식별자는 `qa/final-mp4/manifest.json`의 SHA-256 `dcf9cfe8236a15ac3fac1a6046ec47b9d619c1d91c907931b163eddb2dd8e6ca`이다. manifest 24개 중 아래 11개를 직접 시각 검토했다.

- 0.000초: 첫 장면 정상 표시.
- 74.900초: 배송 결과·강조와 배송 자막 일치.
- 82.967초: 배송 결과 확대에서 분류와 근거 읽기 가능.
- 90.800초 / 91.333초: 배송 장면 끝에서 환불 장면으로 바뀌고 환불 설명·화면 일치.
- 99.700초 / 106.700초: 미분류 결과와 설명 일치, 확대 결과 읽기 가능.
- 113.733초 / 114.467초: 미분류 장면 끝에서 실행결과 표로 정상 전환. 실행 확인 footer 일치.
- 126.317초: 미측정 설명 중 관련 없는 환불 행만 강조하는 문제가 없음.
- 188.900초: 마지막 마무리 장면이 정상 표시되며 검은 화면이나 빈 화면이 아님.

**후속 판정: 최종 MP4의 검토한 프레임 시각 검수 통과.** 확인한 샘플에서 누락·잘림·자막 중첩·화면 의미 불일치 P0/P1을 발견하지 않았다. 위의 최종 MP4 샘플 확인 조건은 충족됐다. 24개 전체 및 모든 인접 프레임을 확인한 것은 아니며 연속 재생, 움직임의 체감 자연스러움, 음성 청취·청감상 싱크는 여전히 미검증이다. 전체 디코드 검사는 상위 제작 담당자의 PASS 보고이며 이 리뷰어가 별도로 재실행하지 않았다.

## 2.1.0 Project Showcase 브랜딩 변경 후 확인

대본과 beat를 유지한 이름 변경에 대해 차등 검토했다. 새 덱의 첫 장과 720p 마지막 장, 배송·환불·표 장면 콘택트시트에서 브랜딩과 레이아웃을 확인했다. 새로 렌더한 MP4는 전체 디코딩을 통과했고 0.7초, 99.7초, 188.9초 실제 프레임에서 새 이름, 미분류 설명과 화면, 마지막 장면을 직접 확인했다. 확인 범위에서 새 시각 결함은 없었다. 전체 청취와 연속 재생은 수행하지 않았다.
