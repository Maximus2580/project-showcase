# 검증 기록 — 2026-11-21

## 현재 판정

구현과 macOS 로컬 생성·렌더 검증 완료. 학생 배포 패키지는 만들었지만 **Windows 실기기와 사람의 최종 청취, 수업 환경의 동시 사용, 실제 학생 프로젝트 30분 완주는 미검증**이다. 예제는 검수 대기로 남겼으며 강사 합격으로 표시하지 않았다.

## 확인한 결과

- 환경: macOS arm64, Node 22.23.2, Python 3.12.13, FFmpeg 8.0.1, HyperFrames 0.9.72, edge-tts 7.3.1.
- edge-tts 실제 서비스에서 한국어 SunHi/InJoon/HyunsuMultilingual 목록 조회 성공.
- 한국어 실제 합성 8개 장면. 예제 음성에서 전체 길이 180.17초 타임라인 생성.
- 완성 MP4: H.264, 1920×1080, 30fps, AAC 음성. ffprobe로 타임라인 길이와 비교 통과.
- 최종 렌더 명령 실행: 약 65.1초. 이 값은 해당 Mac과 해당 예제의 렌더 시간이며 전체 제작 시간이나 학생 PC 성능 보장이 아니다.
- 실제 TTS 최초 예제 호출 18.9초, 수정된 긴 대본 31.8초. 캐시 재사용 경로도 실행했다. 서비스 응답 시간 보장 아님.
- 최종 자동 검사 약 9.9초, 지정 프레임 캡처 약 7.3초.
- 덱 8장: 리소스/JS 오류·넘침 없음. 방향키 이동 통과. 1280×720 투사 화면 생성.
- HyperFrames: lint 오류/경고 0, runtime 오류 0, layout 이슈 0, craft 경고 0. contrast 경고 2건은 밝은 패널을 어두운 배경으로 판단한 결과. 실제 원본 프레임에서 대비를 확인하고 검토 기록에 남김.
- 영상 자막 전 cue: 최대 두 줄과 지정 안전영역 검사 통과.
- 장면·전환 프레임 40개를 콘택트시트 5개로 직접 확인. 데모 2장은 원본 크기 확인. 완성 MP4에서 데모·마지막 프레임을 다시 추출해 확인.
- 음량 측정: mean -17.2 dB, max -3.0 dB. 무음 트랙이 아님을 측정했으나 발음·자연스러움 청취를 대신하지 않는다.
- fixture 실제 브라우저 테스트: 배송 문의, 환불 문의, 담당자 확인 필요의 3개 입력·출력 통과. fixture는 LLM을 사용하지 않는 키워드 분류 예제이며 고객 성과가 아니다.
- 한글·공백 출력 경로에서 init/doctor/build 성공.
- 단위/행동 테스트 14개 통과: 타이밍 누적, 길이 게이트, 캐시 키 변경, 음성 손상, 검사 미실행 거부, 민감파일 제외, 경로 이탈 거부, 슬라이드/ID 검증, production 실제 화면 요구, 리뷰 무효화, 장면 재정렬, 초기화 보존, SRT 시간 올림, 미검토 완료 거부.
- SKILL.md 구조 검증 통과.

## 남은 배포 확인

1. 강사가 예제 MP4 3분을 실제 재생해 한국어 발음, 자막·화면 관계, 마지막 음절 확인.
2. Windows PC에서 설치와 전체 파이프라인 실행. Python 3.12 권장. 코드에 macOS 고정 실행 경로는 없음.
3. 실제 학생 프로젝트 1개를 수정/학생 확인 시간까지 포함해 30분 측정.
4. 수업 네트워크에서 여러 학생의 TTS 실행과 실패 시 재개 확인.
5. 웹앱 외 실제 자동화 스크립트/실행 실패 프로젝트는 지침과 단위 테스트만 있으며, 완성 영상 행동 시험을 추가해야 함.
